Notes on setting up my local knowledge base.

I want a place to collect things I'm learning without having to organize them
perfectly. The idea is to write first, categorize later.

## Why not just use Notion?

Notion is great but I find myself spending more time organizing than writing.
Also, I want my notes to be plain text files I control.

## Setup

Clone the repo and run the build script:

    python -m hunch.build

Open `output/index.html` in a browser.

That's it. No accounts, no syncing, no block editors.
